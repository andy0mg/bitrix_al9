# Оценка ИТ-продукта (ЕЦПК) — портал 1С-Битрикс24

Заполненный шаблон оценки совместимости с ЕЦПК применительно к **порталу 1С-Битрикс24 (коробочная версия)** с опорой на:

- официальный [bitrix-tools/env-docker](https://github.com/bitrix-tools/env-docker/);
- Helm-чарт Yandex Cloud `bitrix-env` 1.0.6 (`appVersion: 9.0.10`).

## Краткие ответы (сводка)

| Критерий | Значение |
|---|---|
| Kubernetes | 1.28 и выше |
| UBI | Alpine; базовые ОС сторонних образов проверяются по SBOM/manifest |
| Описание контейнеров | Предоставлено |
| Объектное хранилище | Yandex Object Storage, S3 API, `csi-s3` |
| Манифест | Helm-чарт Yandex Cloud 1.0.6; дополнительно `docker-compose.yml` |
| Transformer | **Контейнеризация не поддерживается**; `transformer` + `transformercontroller` 20.100.0+, Erlang, RabbitMQ Server, LibreOffice, FFmpeg; серверная роль требует PHP и сайт Битрикс, но может обслуживать другие сайты |
