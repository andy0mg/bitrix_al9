# Оценка ИТ-продукта (ЕЦПК) — портал 1С-Битрикс24

Заполненный шаблон оценки совместимости с ЕЦПК применительно к **порталу 1С-Битрикс24 (коробочная версия)** с опорой на официальное контейнерное окружение [bitrix-tools/env-docker](https://github.com/bitrix-tools/env-docker/).

## Краткие ответы (сводка)

| Критерий | Значение |
|---|---|
| Kubernetes | Kubernetes не поддерживается (оркестрация — Docker Compose) |
| UBI | Alpine (основной стек; MySQL — RHEL) |
| Описание контейнеров | Предоставлено |
| Объектное хранилище | Поддержка S3 API (модуль облачных хранилищ продукта) |
| Манифест | Наличие манифеста в другом формате (`docker-compose.yml`) |
| Transformer | **Контейнеризация не поддерживается**; состав: модули `transformer` + `transformercontroller`, пакеты `erlang`, `rabbitmq-server`, `libreoffice-headless`, `ffmpeg`; **не может работать отдельно от PHP** (только на app-ноде с PHP-FPM) |
