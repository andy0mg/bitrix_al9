# Описание контейнеров: портал 1С-Битрикс24 (env-docker)

Источник: официальный репозиторий [bitrix-tools/env-docker](https://github.com/bitrix-tools/env-docker/) (`docker-compose.yml`, раздел «Текущие версии» README).

Оркестрация: **Docker Compose** (не Kubernetes). Образы публикуются в `quay.io/bitrix24/*` и официальных registry Docker Hub.

## Состав сервисов

| Сервис Compose | Образ (по умолчанию) | Назначение |
|---|---|---|

| `nginx` | `quay.io/bitrix24/nginx:1.30.4-v1-alpine` | HTTP(S), раздача статики, прокси на PHP-FPM |

| `memcached` | `memcached:1.6.45-alpine` | Альтернативный кеш |
| `push-pub` | `quay.io/bitrix24/push:3.3-v1-alpine` | Push-сервер (режим pub) |

## Тома данных

- `www_data` — файлы сайта
- `bxtemp_data` — временные файлы вне document root
- `mysql_lib_data` / `mysql_log_data` — данные и логи MySQL
- `postgres_data` — данные PostgreSQL
- `redis_data` — данные Redis
- `ssl_data`, `msmtp_data`, `browscap_data`, `geoip2_data` — вспомогательные

## Базовые ОС образов (UBI)

- **Alpine** — php, nginx, push, sphinx, ssl, lego, redis, memcached
- **RHEL** — percona-server
- **Debian (trixie)** — postgres (официальный образ)

## Роль Transformer — без контейнеризации

В [bitrix-tools/env-docker](https://github.com/bitrix-tools/env-docker/) **нет** сервиса/образа для Transformer. Роль Document Converter контейнеризацию **не поддерживает**.

### Состав

| Часть | Что входит |
|---|---|
| Модули Битрикс24 | `transformer`, `transformercontroller` (редакция **Энтерпрайз**) |
| ОС-пакеты | `erlang`, `rabbitmq-server`, `libreoffice-headless`, `ffmpeg` |
| Конфиг | `/etc/bitrix-transformer.env` (RabbitMQ: host/port/user/password/vhost) |

### Зависимость от PHP

Transformer **не может жить отдельно от PHP**: ставится только на app-ноду вместе с PHP-FPM. Очередь конвертации и вызов LibreOffice/ffmpeg выполняются из PHP-контекста портала (модули `transformer` / `transformercontroller`). Отдельного автономного сервиса вне PHP-приложения нет.

Ограничение вендора: Transformer — не более чем на **одной** app-ноде.

## Замечания для ЕЦПК

1. Официальный env-docker — **dev/пример** контейнерного окружения; для production вендор рекомендует доп. hardening.
2. Манифест приложения: **Docker Compose**, не Helm.
3. Объектное хранилище S3 настраивается в продукте Битрикс24 (модуль облачных хранилищ), а не как отдельный сервис compose.
4. На хостах с ОС ФСТЭК (Astra Linux SE 1.8, Альт 10 СП) в README env-docker описан запуск Docker/Compose из репозиториев ОС.
5. Роль **Transformer** в контейнеры не выносится и не существует отдельно от PHP/app-ноды.
